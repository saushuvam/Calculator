## 📖 About

This is a simple and responsive **Calculator Web Application** built using **HTML, CSS, and JavaScript**.
The app performs basic arithmetic operations and provides a clean user interface similar to a real calculator.

It is designed to practice:

* DOM manipulation
* Event handling
* User input processing
* Basic logic building in JavaScript

## ✨ Features

✔ Addition, subtraction, multiplication & division
✔ Clear (AC) button
✔ Delete (⌫) last digit
✔ Decimal number support
✔ Keyboard-friendly usage
✔ Responsive design (works on mobile & desktop)

---

## 🎮 How to Use

1. Open the calculator
2. Click the number buttons
3. Select an operator (+, −, ×, ÷)
4. Press **=** to get the result
5. Use **AC** to reset
